# Git-процесс

Работай напрямую в ветке `main` — не создавай отдельные feature/fix-ветки
под задачи, если пользователь явно не попросил ветку. Коммить и push —
только когда пользователь явно попросит (например, «push» или «закоммить»);
не коммить и не пушить самостоятельно по умолчанию.
