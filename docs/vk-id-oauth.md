# VK ID OAuth — известная проблема с правами wall/photos/groups

Код публикации в ВК (`src/lib/vk.ts`, `/api/vk/authorize`, `/api/vk/callback`)
запрашивает scope `"wall photos groups offline"` — но реально выданный токену
scope (проверено в проде 9 ноября 2026) оказался только:

```
offline vkid.personal_info
```

То есть `wall`/`photos`/`groups` VK не выдал, хотя код их запросил корректно.

## Вероятная причина

VK ID (`id.vk.ru`) — отдельная система авторизации от классического VK API
OAuth (`oauth.vk.com`), с отдельной моделью прав. По документации и беглому
поиску, `vkid.personal_info`/`email`/`phone`/`offline` — это базовый набор,
который VK ID выдаёт сразу. А права вроде `wall`/`photos`/`groups` относятся
к «расширенным» и, похоже, требуют **подтверждения бизнес-профиля приложения
в кабинете VK ID Business** (`id.vk.ru/business/go` → настройки приложения →
раздел доступов) — без этого VK тихо срезает их из выданного scope, даже если
они явно перечислены в `scope=` при авторизации.

Это не воспроизвести и не починить кодом сайта — нужно проверять/настраивать
в личном кабинете VK ID Business.

## Как перепроверить после изменений в кабинете VK

1. Пройти авторизацию заново: `/api/vk/authorize` (под администратором).
2. Проверить реально выданный scope — `npx tsx scripts/check-vk-oauth-status.ts`
   (только показывает `scope`/`expiresAt`, сами токены не выводит).
3. Если в scope появились `wall`/`photos`/`groups` — попробовать публикацию
   через кнопку «Опубликовать в ВК» в карточке объекта.

## Проверка через скрипт (не кнопку в админке)

`scripts/test-vk-publish.ts` вызывает ту же функцию `publishListingToVk`, что
и кнопка в админке, но локально. Важно: VK ID привязывает access_token к IP,
с которого его получили/обновили — при запуске не с продакшен-сервера первым
делом вернётся ошибка `[код 5] User authorization failed: access_token was
given to another ip address`, которая не говорит ничего про scope. Достоверно
проверить права можно только с того же IP, с которого токен обновлялся —
то есть кликом по кнопке в реальной админке на проде.
