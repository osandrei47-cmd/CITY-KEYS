# Cookie-политика

## Что такое cookie

Cookie — небольшие текстовые файлы, которые сохраняются в браузере Пользователя при посещении сайта и используются для улучшения работы сайта и анализа посещаемости.

## Какие cookie использует сайт

- Технические (необходимые) — обеспечивают базовую работу сайта (например, сохранение выбранных фильтров в каталоге)
- Аналитические — Яндекс.Метрика, используется для анализа посещаемости и поведения пользователей на сайте

## Согласие на использование cookie

При первом посещении сайта Пользователю показывается баннер с возможностью:

- Принять использование всех cookie
- Отказаться от аналитических cookie (технические cookie при этом продолжают работать, так как необходимы для базовой функциональности)

Аналитические cookie не устанавливаются до получения явного согласия Пользователя.

## Управление cookie

Пользователь может в любой момент изменить настройки cookie в своём браузере, включая полный запрет на их сохранение — в этом случае часть функций сайта может работать некорректно.
